Zyro Browser

A desktop web browser written from scratch in C++. Version one ran on WebKitGTK with a custom HTML/CSS interface — and showed me exactly where a single-process design runs out of road. Version two is a rebuild on the Chromium Embedded Framework.

  • Multi-process architecture, built with CMake
  • CEF views embedded in a GTK3 window
  • V8 IPC bridge between the browser UI and native code
  • Network request interception
